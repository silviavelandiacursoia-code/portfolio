# Silvia Velandia | Portfolio profesional & Atelier

Portfolio personal creado con React, TypeScript, Vite y Tailwind CSS.

## Requisitos

- Node.js 20.19 o posterior (se recomienda la versión LTS).
- npm, incluido con Node.js.

## Desarrollo local

1. En PowerShell, instala las dependencias:

   ```sh
   npm.cmd install
   ```

2. Inicia el servidor de desarrollo:

   ```sh
   npm.cmd run dev
   ```

3. Abre [http://localhost:3000](http://localhost:3000).

No se necesita configurar una clave de Gemini ni crear un archivo `.env.local`.

## Comprobaciones

```sh
npm.cmd run lint
npm.cmd run build
```

Para servir la compilación localmente, ejecuta `npm.cmd run preview`.
